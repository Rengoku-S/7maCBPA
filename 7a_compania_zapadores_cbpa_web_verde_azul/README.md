# Sitio web — 7ª Compañía Zapadores CBPA

Prototipo estático responsive para la Séptima Compañía del Cuerpo de Bomberos de Puente Alto.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive.
- `script.js`: menú móvil y pequeñas interacciones.
- `assets/`: carpeta preparada para fotografías, logos y material propio.

## Datos incorporados
- Fundación: 7 de marzo de 2013.
- Cuartel histórico/de fundación: Elisa Correa N.º 570.
- Especialidades: Agua y Escala.
- Primera oficialidad histórica de 2013.
- Primer carro portaescalas/Q7 como antecedente histórico.
- Brigada Juvenil: referencia pública a su primer aniversario en julio de 2026.
- Noticias y enlaces a fuentes oficiales.

## Importante
Las secciones de oficialidad vigente y material mayor actual están deliberadamente marcadas como "por actualizar" porque deben completarse con información institucional vigente antes de publicar el sitio.

## Cómo abrir
Haz doble clic en `index.html` o usa VS Code + Live Server.

## Para convertirlo en sitio dinámico
Se puede migrar posteriormente a Django:
- `/noticias/`
- `/llamados/`
- `/carros/`
- `/oficialidad/`
- panel de administración para editar contenido
- carga de fotografías
- formulario de contacto/donaciones
- base de datos MySQL/MariaDB
